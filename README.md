# Plataforma de cartillas

Plataforma web de cartillas interactivas por materia y grado, con modos estudiante, docente y coordinador. La primera cartilla es English Adventure Quest (inglés, grado tercero).

El contexto y las reglas del proyecto están en `CLAUDE.md`. El equipo de agentes está en `.claude/agents/` y las skills en `.claude/skills/`.
